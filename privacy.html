Privacy Policy

Effective date: September 28, 2026

This policy explains how shorts-pipeline, the private production tool operated by ShortsLab (an individual creator in Busan, South Korea), uses Google user data. The tool is used only by the operator, for the operator's own two YouTube channels: 살아보니 and 댓글판사.

1. Google permissions we request and why

Permission (scope)What it is used for
https://www.googleapis.com/auth/youtube.uploadUploading a finished video to the operator's own channel, only after the operator approves that video.
https://www.googleapis.com/auth/youtube.readonlyConfirming which channel is signed in, checking that an upload arrived with the right privacy status, and avoiding duplicate uploads.
https://www.googleapis.com/auth/yt-analytics.readonlyReading basic performance numbers (views, average view percentage, subscriber changes) for the operator's own channels.

The tool does not request permission to delete videos, edit existing videos, change channel settings, or post comments.

2. What data we access

Only data belonging to the operator's own YouTube channels: channel name and ID, the operator's own uploaded videos and their status, and aggregate analytics for those channels. We do not collect, access, or store data about any other YouTube user or any viewer.

3. Where data is stored

OAuth access and refresh tokens are stored only on the operator's own computer, in a file readable only by the operator's account. Tokens are never sent to any server other than Google's, never shared, and never published. Analytics numbers are kept in local log files on the same computer and in private notifications to the operator.

4. Sharing

We do not sell, rent, or share Google user data with any third party. We do not use Google user data for advertising.

5. Retention and deletion

Tokens are kept only while the tool is in use. To delete them, the operator removes the token files from the computer and revokes access as described below. Local analytics logs are kept for the operator's own review and can be deleted at any time. If you have any question about data related to this tool, contact us and we will respond and delete relevant data on request.

6. How to revoke access

Access can be revoked at any time from your Google Account permissions page: https://myaccount.google.com/permissions.

7. YouTube and Google policies

This tool uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service. For how Google handles data, see the Google Privacy Policy.

8. Changes

If this policy changes, the new version will be posted on this page with a new effective date.
